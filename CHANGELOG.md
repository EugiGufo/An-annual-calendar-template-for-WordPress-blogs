# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-06

### Added
- Initial public release of the WordPress annual calendar page template.
- Year navigation covering the blog's published history.
- Monthly calendar grids with links to dates and months containing published posts.
- Post-count information in the `title` attribute of linked dates.
- "Today in the past years" visual marker.
- Responsive month layout for desktop and smaller screens.
- Installation instructions and GPL-2.0-or-later licensing information.
